# Salsy 1.1.11 – oppdatert logo i PC og nettklienter

Server og PC oppdateres til **1.1.11**. Salsy Android beholder **1.0.1**, som allerede har den godkjente logoendringen.

PC-klientens sidemeny og serverens nettklienter viser nå Salsy-logoen med gjennomsiktig bakgrunn og en tynn hvit kontur rundt bokstavene og symbolet. Originalfargene beholdes. Den hvite ruten rundt logoen er fjernet. Endringen gjelder `/app/`, `/app/salsy/` og regnskapsførerens sider, både i lys og mørk modus.

Installer serveroppdateringen, start serveren på nytt og last nettappene på nytt. PC-programmet må også oppdateres for å få endringen i den lokale sidemenyen. Ingen ny Caddyfile kreves. Innlogging, bedriftsdata, beregninger og eksportformater er uendret.

Kontrollene omfatter ekte Tk-visning og nettleservisning med syntetiske data, temabytte og PC-/nettparitet. Installasjonspakkene kontrolleres for riktige versjoner, nettressurser og avhengigheter. ARM64-pakken bygges fra samme serverkode. Fysisk Android/iPhone/ARM-enhet og faktisk systemd-oppstart er ikke testet. Hosting Manager følger serverversjonen, men publiseres ikke på GitHub.

Tariffavtalenes eksisterende kontrollstatus og Kasses teststatus beholdes.

## English

Server/PC **1.1.11** use transparent Salsy artwork with a thin white contour, matching Android **1.0.1**. Removes the white logo panel from the native PC sidebar and web clients, including the accountant workspace. Original colours are preserved in both themes. Restart the updated server and reload web apps; update native PC separately. No new Caddyfile is required. Data, authentication, calculations and exports are unchanged. Private Hosting Manager packages remain excluded from GitHub.
