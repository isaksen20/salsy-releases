# Salsy 0.95.7 – Nettsidelenke i Brukerstøtte

En klikkbar **https://salsy.eu/** ligger nå under **support@salsy.eu** i
Innstillinger på PC, PC-nett, mobilnett, Warehouse og Android-appene.
Regnskapsførersiden har kontaktfeltet nederst, og PRP har en Brukerstøtte-knapp.
Nettklientene åpner lenken i en ny fane; Linux og Android bruker enhetens
nettleser. Linux-lenkene støtter også Enter og mellomrom.

Inkluderer server/PC **0.95.7**, Salsy Android **0.35.6**, Warehouse Android
**0.11.4**, PRP **0.2.28** og Kasse **0.1.3** for Linux/Android.
Oppdaterte bruksanvisninger for Salsy og regnskapsfører følger med.
Oppdater server og aktuelle programmer, start serveren på nytt og last
nettklientene på nytt. Privat Hosting Manager **0.95.7+hosting.1** beholdes
lokalt og installeres sammen med matchende serverpakke.

Dette endrer ikke rettigheter eller lønns-/regnskapsberegninger. Tariffmaler
beholder eksisterende kontrollstatus, og regnskap er fortsatt skyggeregnskap.
Fysiske Android-/ARM-enheter og faktisk systemd-oppstart er ikke testet.
ARM64-serverpakken kontrolleres i QEMU.

## English

The Support area links to the official website below the support email across
PC, mobile and Warehouse clients, including Android Checkout. The accountant
workspace includes the same contact panel; PRP has a Support toolbar button.
Web clients open a new tab, and native applications use the device browser.
Updated Norwegian general and accountant PDF manuals are included. Restart the
updated server and reload web clients. The matching private Manager stays local.
No permissions or financial calculations change; existing tariff coverage and
shadow-accounting limitations remain. Physical Android/ARM and OS boot are not
tested; ARM64 package checks use QEMU.
