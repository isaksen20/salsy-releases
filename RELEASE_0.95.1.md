# Salsy 0.95.1 – Kronologiske minioppgaver i kalenderen

Tildelte minioppgaver med klokkeslett vises nå fra tidligst til senest i
kalenderen, også etter at en oppgave legges til eller fjernes i det åpne
kalendervinduet. Ved lik starttid sorteres det på sluttid og navn. Oppgaver
uten starttid vises nederst. Biblioteket beholder alfabetisk rekkefølge.

Sorteringen kommer fra den felles serveren og gjelder PC-klienten,
PC-nettklienten og mobilklientene. Alle funksjoner fra 0.95.0 videreføres,
inkludert ferieoppgjør, utvidet regnskapsførerportal og personalverktøy.
Oppdater server og PC til 0.95.1, start serveren på nytt og last nettsiden på
nytt. Android-appene har samme versjoner som i 0.95.0.

[Personalverktøy](STAFF_TOOLS.md) · [Ferieoppgjør](VACATION_FINANCE.md)

English: Assigned mini tasks now appear in chronological order in calendars,
including live assignment refresh. Tasks without a start time appear last.
This is a shared server correction for native PC, desktop web and mobile.
